# Quick Installation Guide

## Install Ctrl+S Tube Chrome Extension in 3 Easy Steps

### Step 1: Open Chrome Extensions
1. Open Google Chrome
2. Type `chrome://extensions/` in the address bar and press Enter
3. **Enable Developer Mode** (toggle switch in the top-right corner)

### Step 2: Load the Extension
1. Click the **"Load unpacked"** button
2. Navigate to this folder: `chrome-extension`
3. Click **"Select Folder"**

### Step 3: You're Done! 🎉
- The extension icon should appear in your Chrome toolbar
- Click the puzzle icon and pin "Ctrl+S Tube" for easy access
- Visit any YouTube video to see the download button

## Testing the Extension

1. **Visit YouTube**
   - Go to https://www.youtube.com
   - Open any video

2. **Use the Extension**
   - Click the Ctrl+S Tube icon in your toolbar
   - The video URL should auto-populate
   - Click "Fetch" to load video info
   - Select Video or Audio
   - Choose quality
   - Click "Download" (Note: requires backend setup for full functionality)

3. **Try the YouTube Button**
   - Look for the red "Download" button below the video
   - It appears next to Like/Dislike buttons

## Troubleshooting

### Extension not loading?
- Make sure Developer Mode is enabled
- Check that you selected the correct folder
- Look for error messages in the Extensions page

### No download button on YouTube?
- Refresh the YouTube page
- Make sure you're on a video page (not home page)
- Check browser console for errors (F12)

### Downloads not working?
- This is expected! The extension needs a backend service
- See README.md for backend setup options
- Or use the desktop Python app for full functionality
